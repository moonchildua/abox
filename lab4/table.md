# retrieval-agent questions and answers: official vs. fixed

The question table from `summary.md`, extended with the answers recorded from retrieval-agent in the two runs:

- **Official**: run B, the official `mcp-server-qdrant` 0.8.1 (`qdrant-store`/`qdrant-find`, MiniLM, 384 dims). Notes in `qdrant-official.md`.
- **Fixed**: run A, the in-house `qdrant-mcp` 0.4.0 (`vector_store`/`vector_find`, nomic via llama.cpp, 768 dims). Notes in `qdrant-den.md`.

Answer columns: what the agent said, where the fact came from, the score (2 correct, 1 partial, 0 wrong), and on a new line the tools in call order.

Score columns: rank of the expected object among the 5 vector search results, its cosine score, and the gap to the neighbour (rank 1 minus rank 2; negative when the expected object is not first). Absolute nomic and MiniLM scores are different scales and are not compared with each other; rank and gap are. Official scores were computed with `score-minilm.py`, because `qdrant-find` does not return them.
